## Activation

Real-data features require a CDK issued for the exact application ID `Mementrail`. The application uses the existing HTTPS activation service, verifies signed licenses locally, and stores activation state with Windows user-bound encryption. Permanent licenses work offline; time-limited licenses require a server-time check at least every 24 hours. About, settings, updates, and fictional demo data remain available without activation.
